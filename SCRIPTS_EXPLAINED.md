# Shell scripts

add_new_method.sh — this is the script that should be ran when you want to add a new method to macro_core.

build_web_and_android.sh — running it means the android and web builds are up to date.

check_everything.sh — self explanatory.

check_specific_file.sh — opens a cli menu to pick from a list, then checks a specific crate.

run_single_test.sh — self explanatory.

tests.sh — runs all tests.
