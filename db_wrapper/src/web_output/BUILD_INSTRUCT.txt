#Web build instructions for db_wrapper

#1. Build the web files:
   wasm-pack build --target web --out-dir src/web_output --out-name db_wrapper --features web --no-typescript --no-pack

#2. Copy the entire web_output/ folder into your web project and make it visible to Trunk

#3. all worker_wrapper.js to send commands to the database worker and receive responses.

#4. The command/response protocol follows the structs defined in the protocol crate (z_db/protocol). Inputs and outputs are (Vec<u8>) and serialize/deserialize via let payload = payload::GetDataIn {bla bla bla}.to_payload and payload.un_payloadify
